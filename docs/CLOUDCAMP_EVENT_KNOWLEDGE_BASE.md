            <h2>5. AI Stack, RAG, Agents & Local Models Guide</h2>
            <p>To achieve top tier AI stack scores, teams should combine frontier cloud LLMs with local model execution, structured RAG architectures, and agentic orchestration.</p>

            <h3>RAG Architecture Strategy</h3>
            <p>Selecting multiple advanced RAG techniques unlocks significant bonus points:</p>
            <ul>
                <li><strong>Contextual RAG:</strong> Prepend chunk-specific context summaries before embedding to preserve global document context.</li>
                <li><strong>Variable / Semantic Chunking:</strong> Split text based on semantic boundaries rather than fixed token lengths.</li>
                <li><strong>Graph RAG:</strong> Extract entity-relation-entity graphs to enable multi-hop reasoning across unstructured data.</li>
            </ul>

            <h3>Agentic & Local Model Integration</h3>
            <p>Combine local runtimes like <code>Ollama</code> or <code>LM Studio</code> running open-weight models (e.g. DeepSeek-R1, Qwen2.5, Llama 3.3) with agentic orchestration frameworks like <code>LangGraph</code> or <code>CrewAI</code>. Disclosing local hardware specs and quantization notes yields additional evaluation points.</p>
        </section>

        <section id="mcp-guide">
            <h2>7. Model Context Protocol (MCP) Integration Guide</h2>
            <p>MCP allows your AI application to connect securely with external context, tools, and data sources. Demonstrating MCP development maximizes your project score.</p>

            <div class="callout success">
                <h4>How to Implement MCP for Bonus Points</h4>
                <ul>

## 2. Idea to Unicorn Track & Master Prompt Rules

            The **Idea to Unicorn** track challenges participants to transform a raw product vision into a full-fledged, scalable startup prototype. It incorporates the strict **Zero to Launch Challenge** prompt constraints.

            
                
#### CRITICAL RULE: Single Master Prompt Constraint

                Participants in the Zero to Launch and Idea to Unicorn prompt challenges must adhere to the **ONE PROMPT ONLY** rule. You must craft a single, comprehensive master prompt that generates or initializes the entire system architecture, modules, documentation, and deployment flow.

            

            
### Required Master Prompt Sections

            Your single master prompt must contain complete instructions covering all of the following core modules:

            
                - **Core Product & AI Instructions:** Product concept, target users, features and functions, user journeys, and demo user persona.

                - **Data Architecture:** Schemas, models, vector store setup, and data pipelines.

                - **Admin Module:** User management, role-based access control, analytics dashboard, and system settings.

                - **Security Module:** Authentication, rate limiting, data encryption, and vulnerability guardrails.

                - **Documentation Module:** System architecture docs, API references, and installation guides.

                - **Audit Reporting:** Automated audit logging, token usage tracking, and compliance checks.

                - **Presentation & Pitch Deck:** Auto-generated slide structures, value proposition, and market analysis.

                - **Deployment Requirements:** Infrastructure config, Docker setup, CI/CD scripts, and environment configuration.

            

            
### Permitted Actions Post-Prompt Execution

            Once the master prompt is executed, user interaction is limited to explicit confirmation triggers:

            
                - "Click to approve"

                - "Click to continue"

                - "Click to proceed"

                - "Yes" / "Continue"

                - "Deploy"

## 5. AI Stack, RAG, Agents & Local Models Guide

            To achieve top tier AI stack scores, teams should combine frontier cloud LLMs with local model execution, structured RAG architectures, and agentic orchestration.

            
### RAG Architecture Strategy

            Selecting multiple advanced RAG techniques unlocks significant bonus points:

            
                - **Contextual RAG:** Prepend chunk-specific context summaries before embedding to preserve global document context.

                - **Variable / Semantic Chunking:** Split text based on semantic boundaries rather than fixed token lengths.

                - **Graph RAG:** Extract entity-relation-entity graphs to enable multi-hop reasoning across unstructured data.

            

            
### Agentic & Local Model Integration

            Combine local runtimes like `Ollama` or `LM Studio` running open-weight models (e.g. DeepSeek-R1, Qwen2.5, Llama 3.3) with agentic orchestration frameworks like `LangGraph` or `CrewAI`. Disclosing local hardware specs and quantization notes yields additional evaluation points.

        

        
            
## 6. Data Lifecycle, Pipelines & Storage Guide

            A complete data stack is required for full technical credit. You must document data flow from ingestion to visualization:

            
                - **Data Sources & Acquisition:** APIs, web scrapers, crawlers, public datasets, or custom MCP data servers.

                - **Parsing & Processing:** Format converters, JSON/CSV/PDF parsers, and schema validation logic.

                - **Data Cleaning & Enrichment:** Deduplication, data imputation, and LLM-assisted entity extraction.

                - **Storage Targets:** Relational databases (PostgreSQL), Vector databases (Pinecone, pgvector), and object storage (S3).

                - **Analytics & Delivery:** BI dashboards, real-time webhooks, outbound REST APIs, and automated reports.

            
        

        
            
## 7. Model Context Protocol (MCP) Integration Guide

            MCP allows your AI application to connect securely with external context, tools, and data sources. Demonstrating MCP development maximizes your project score.

            
                
#### How to Implement MCP for Bonus Points

                
                    - Build at least 1 custom MCP server (e.g. exposing custom database queries or business logic tools).

                    - Integrate at least 1 existing public MCP server (e.g. PostgreSQL MCP, GitHub MCP, Fetch MCP).

                    - Support standard MCP transports: Streamable HTTP / Server-Sent Events (SSE) or Stdio.

                    - Provide clear MCP client/host disclosure and permission boundary notes in your submission text.
